## Done (meets or supersedes ticket intent)

### Envoy JWT gateway

Implemented in [`internal/resources/envoy.go`](../../internal/resources/envoy.go), applied in `reconcileEdge`:

- `EnvoyConfigMap` — ConfigMap key `envoy.yaml` from `EnvoyYAML`
- `EnvoyService` — ClusterIP, port 80 → container `http` (9080), admin 9901
- `EnvoyDeployment` — image from `spec.auth.envoy` or OSSM proxyv2 default; replicas default 2; CA-combine init; readiness on admin `/ready`; pod-template annotation `koku.costmanagement.io/envoy-config-hash` rolls pods on config change
- Names: `{cr}-gateway`, `{cr}-gateway-envoy-config` (`NameEnvoy`, `NameEnvoyConfigMap`)

### OIDC wiring from CR

| Helper | CR source | Envoy use |
|--------|-----------|-----------|
| `KeycloakIssuerURL` | `spec.auth.keycloak.issuerURL` or `url` + realm | JWT `issuer` |
| `KeycloakAudiences` | `spec.auth.keycloak.audiences` (CRD defaults) | JWT `audiences` |
| `KeycloakJWKSURL` | always from `url` + realm | `remote_jwks` URI (in-cluster fetch) |

`spec.auth.keycloak.tls.caCertSecretName` is mounted into Envoy’s `prepare-ca-bundle` init at `/ca-extra` and merged into the JWKS trust bundle. `insecureSkipVerify` sets Envoy JWKS `trust_chain_verification: ACCEPT_UNTRUSTED` unless a CA secret is also set (CA wins).

Unit coverage in [`envoy_test.go`](../../internal/resources/envoy_test.go).

### Ingress upload service

Implemented in [`internal/resources/ingress.go`](../../internal/resources/ingress.go), applied in `reconcileWorkers` (before Edge so Envoy has a backend):

- `IngressDeployment` + `IngressService` — ports **8080** (http) / **9000** (metrics)
- S3 via `INGRESS_MINIOENDPOINT` (`ingressS3Endpoint`, prefers discovered endpoint), keys from storage Secret
- Kafka brokers / announce topic / optional SASL
- `INGRESS_AUTH=true` (trusts Envoy-injected `X-Rh-Identity`)
- CA combine init + `SSL_CERT_FILE`
- Workers call `isDeploymentReady` and set `IngressReady` (`WaitingForIngress` / `IngressReady`); unready Ingress requeues and blocks Edge

### Gateway Route (supersedes ticket minimum)

[`GatewayAPIRoute`](../../internal/resources/route.go) — OpenShift Route `{cr}-api` path `/api` → Envoy Service; host from `gatewayRoute.host` or `{name}-gateway-{ns}.{clusterDomain}`. `passthrough` / `reencrypt` are coerced to `edge` because Envoy listens plaintext HTTP (full TLS story remains COST-7691 / D19). Covered by [`route_test.go`](../../internal/resources/route_test.go).

### Status reporting

| State | Condition | Reason |
|-------|-----------|--------|
| JWKS probe (Validation) | `AuthenticationReady` | `OIDCReachable` / `OIDCUnreachable` |
| Envoy not ready | `GatewayReady=False` | `WaitingForGateway` |
| Envoy ready, no Route host | `GatewayReady=False` | `ClusterDomainPending` |
| Envoy + Route ready | `GatewayReady=True` | `GatewayReady` |
| Ingress not ready | `IngressReady=False` | `WaitingForIngress` |
| Ingress ready | `IngressReady=True` | `IngressReady` |

Edge does not write `AuthenticationReady`. Tests: [`edge_test.go`](../../internal/controller/edge_test.go), [`workers_ingress_test.go`](../../internal/controller/workers_ingress_test.go).
